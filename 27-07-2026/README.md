# GitLift Phase 1 — Neo4j Query Engine

A read-only natural language interface for the **UST PACE Neo4j graph database**. Ask questions in plain English and get answers — no Cypher or graph database knowledge required.

Two query modes are available:
- **NLP Engine** (`nlp_engine.py`) — instant, pattern-based, no API key needed
- **LLM Engine** (`llm_query_engine.py`) — free-form English via Google Gemini AI

> **Safety guarantee:** All query paths enforce strict read-only access. `CREATE`, `DELETE`, `MERGE`, `SET`, and all other write operations are blocked at the code level before reaching the database.

## Installation

**Step 1 — Clone or download this project folder** to your machine.

**Step 2 — Open a terminal** (Command Prompt, PowerShell, or any terminal) and navigate to the project folder:

```bash
cd path\to\GitLift-Phase1
```

**Step 3 — Install all required Python packages:**

```bash
pip install -r requirements.txt
```

This installs:
- `neo4j` — official Neo4j Python driver
- `openai` — OpenAI SDK (included for future use)
- `google-generativeai` — Google Gemini SDK (used by the LLM engine)

## Configuration

### Neo4j Connection

The database connection details are already set inside each script:

```
URI      : bolt+s://neo4j-bolt.ustpace.com:7687
Username : neo4j
Password : password123
```

No changes are needed unless the credentials change.

### Google Gemini API Key (only for LLM Engine)

The LLM engine (`llm_query_engine.py`) requires a free Google Gemini API key.

**Step 1 —** Get a free API key at: https://aistudio.google.com/app/apikey

**Step 2 —** Set it as an environment variable:

- **Windows (PowerShell):**
  ```powershell
  $env:GEMINI_API_KEY = "your_api_key_here"
  ```
- **Windows (Command Prompt):**
  ```cmd
  set GEMINI_API_KEY=your_api_key_here
  ```
- **macOS / Linux:**
  ```bash
  export GEMINI_API_KEY="your_api_key_here"
  ```

> The NLP engine (`nlp_engine.py`) does **not** need an API key.

## Running the Scripts — Step by Step

Follow this order the **first time** you set up the project. After that, you can jump directly to Step 3 or Step 4.

---

### Step 1 — Discover the Database Schema

Run this once to verify connectivity and see what data exists in the graph.

```bash
python discover_schema.py
```

**What it does:**
- Connects to the Neo4j database
- Prints all node types (e.g., Repository, File, API, Pipeline) with counts
- Prints all relationship types
- Lists all properties for each node type
- Saves the full report to `schema_report.txt`

**Expected output (excerpt):**
```
[OK] Connected to Neo4j (READ-ONLY mode)

======================================================================
NEO4J SCHEMA DISCOVERY REPORT
======================================================================

NODE LABELS (with counts)
----------------------------------------------------------------------
   Symbol                                   ->  1,822,645 nodes
   File                                     ->    130,405 nodes
   Repository                               ->        493 nodes
   ...
```

---

### Step 2 — Run the Safety Tests (Optional but Recommended)

These scripts confirm that the read-only protection is working and verify your database access level.

#### Test A — Read-only safety layer

```bash
python test_readonly.py
```

This verifies that write commands (`CREATE`, `DELETE`, etc.) are blocked before reaching the database. All tests should say `CORRECTLY BLOCKED`.

#### Test B — Database write permissions

```bash
python test_write_permissions.py
```

This tests whether the database account actually has write access. Expected output is `NO WRITE ACCESS`, confirming the database user is restricted.

---

### Step 3 — Use the NLP Query Engine (No API Key Required)

The NLP engine matches your question against a set of predefined templates and runs the corresponding Cypher query.

```bash
python nlp_engine.py
```

**What you will see:**
```
======================================================================
GitLift NLP Query Engine (READ ONLY)
Type 'exit' to quit
======================================================================

Ask:
```

Type a question and press Enter. Type `exit` to quit.

> **Note:** This engine recognises a fixed set of phrases. See [Query Examples](#query-examples) below for what it understands.

---

### Step 4 — Use the LLM Query Engine (Requires Gemini API Key)

The LLM engine accepts any question in natural English. Google Gemini translates it into a Cypher query, which is then executed against the database.

**Make sure your API key is set** (see [Configuration](#configuration) above), then run:

```bash
python llm_query_engine.py
```

**What you will see:**
```
======================================================================
  GitLift LLM Query Engine (Google Gemini)
  Free-form English → Cypher → Neo4j
  READ-ONLY MODE
======================================================================
[OK] Gemini API connected
[OK] Connected to Neo4j @ bolt+s://neo4j-bolt.ustpace.com:7687 (READ-ONLY)

💬 Type your questions in English
   Type 'exit', 'quit', or 'q' to stop

🔍 Ask:
```

Type any question in plain English and press Enter. The engine will:
1. Send your question to Gemini to generate a Cypher query
2. Validate the query is read-only
3. Execute it against the database
4. Display the results

## Query Examples

### NLP Engine — Supported Phrases

The NLP engine recognises these exact phrase patterns:

```
# Counts
how many nodes
how many relationships
how many repositories
how many apis
how many pipelines
how many methods
how many classes

# Listings
show repositories          list repositories
show repos                 list repos
show apis                  list apis
show services              list services
show pipelines             list pipelines
show github repos          list github repos
show github members        list github members

# Schema
list labels
list node types
show relationship types
relationship types
```

### LLM Engine — Example Free-Form Questions

```
Which repositories use Python?
How many files are in the repository named "auth-service"?
Show me all pipelines that deploy to production
List all APIs exposed by the payment service
Which methods call other methods more than 5 times?
Show GitHub members who have been inactive for more than 30 days
What CI/CD tools are used across all pipelines?
```

## Troubleshooting

| Problem | Likely Cause | Fix |
|---|---|---|
| `Connection refused` or `ServiceUnavailable` | No internet, or the Neo4j server is down | Check your internet connection and try again |
| `AuthError` | Wrong username or password | Verify credentials in the script |
| `GEMINI_API_KEY is not set` | Environment variable missing | Set `GEMINI_API_KEY` as shown in [Configuration](#configuration) |
| `Model unavailable` from Gemini | Wrong model name or quota exceeded | Check your Google AI Studio quota |
| `WRITE OPERATION BLOCKED!` | A generated Cypher query contained write keywords | This is the safety system working correctly — the query was rejected |
| NLP engine says "No results found" | Your phrase doesn't match any template | Use exact phrases from the [Query Examples](#query-examples) table, or switch to the LLM engine |
| `ModuleNotFoundError` | Packages not installed | Run `pip install -r requirements.txt` again |
